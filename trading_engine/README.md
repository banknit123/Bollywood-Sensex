# Trading Engine

Safety-first research and paper-trading engine for Indian equities.

## Build order
1. Historical market data
2. Feature generation
3. Signal generation
4. Backtesting with costs/slippage
5. Paper trading
6. Risk controls
7. Broker adapter (disabled for live trading by default)

## Important
Live order submission must remain disabled until a strategy has passed backtest and paper-trading validation. This module is for research and controlled execution, not guaranteed profitability.
